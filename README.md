
# Python Chatbot with Sentiment Analyzer

A simple rule-based python chatbot that uses textBlob to analyze text input. This input is then used to generate some generic results that a customer might be asking the chatbot.

The Chatbot is based for a simple Mom and Pop business that can help customers answer general queries.


## Running the project

To deploy this project run

```bash
  python3 chatbot.py
```
